# pocket-monsters for android 14
Combact monsters, collect candys and equip artifacts!

## Setup

1. Get a Google Maps API key from: https://developers.google.com/maps/documentation/android-sdk/get-api-key
2. Copy `secrets.defaults.properties` to `secrets.properties` (or add to existing `local.properties`)
3. Replace `YOUR_API_KEY_HERE` with your actual API key:
   ```
   MAPS_API_KEY=your_actual_key_here
   ```
4. Build the project

5. Now add the api.url in your secrets.properties file
